# grade-request

Static page for Semantic Web students to ask Prof. Remzi Celebi (Maastricht University) for their grade details.

One button opens a randomly chosen, pre-written, polite draft in the student's mail client. Alternative buttons open Outlook on the web or the Outlook app. An optional name field is used only to sign the draft. Nothing is collected, stored or transmitted by the page.

No build step. Edit the recipient and draft texts at the top of `script.js`.
